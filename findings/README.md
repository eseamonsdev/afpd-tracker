# Findings

Research notes and analysis supporting the AFPD accountability project.

This folder lives at the repository root, outside the website's `src/` input and `public/` output. Its files are not included in website navigation, the radio index, or the sitemap. They remain readable in this public GitHub repository.

The recordings and each day's `calls.json` remain the underlying evidence. Findings should distinguish recorded facts, transcript uncertainty, and analytical inference. Preserve clip numbers, Mountain times, and source references when updating a finding.
