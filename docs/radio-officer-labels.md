# Dated officer labels

The archive uses `public/records/openmhz/officer-associations.json` for the names beside radio IDs in clip rows and the player. Both displays use the same lookup, keyed by the selected archive date and transmitting radio ID. IDs are always bold; names have regular weight.

This is a curated display list, not the radio inventory or a permanent assignment list. Each entry records the full name and supporting spreadsheet evidence IDs (or archive clip numbers). Do not extend an association to dates without supporting named exchanges.

The initial list uses the named identities in the rendered Police Radio Resources table and the dates in the response spreadsheet. It omits roster candidates, unresolved/conflicting identities, and dates where the only name reading is uncertain. Owner-confirmed name corrections are included. September 19's Sam/14590100 and October 1's unclear Makai/14590247 reply remain excluded. Choates/14590313 and Ivan/14590165 use the dated exchanges documented in the resource table; Choates/14590045 remains uncertain.

When resolving or correcting an association, update the spreadsheet, resource table, and this dated list together. A transcript's verified flag concerns its wording and is separate from this association list.

The label describes a radio association for that date. It does not independently establish who speaks in every transmission. The archive explains this beside the date selectors. Missing or unavailable association data falls back to ID-only playback.
