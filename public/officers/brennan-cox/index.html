UCJIS (Utah Criminal Justice Information System) User ID

UCJIS is Utah’s secure criminal justice information system, managed by the Utah Bureau of Criminal Identification (BCI). It provides authorized access to state and federal databases, including the FBI’s National Crime Information Center (NCIC). An agency’s Terminal Agency Coordinator (TAC) assigns each user an individual account and User ID. See BCI’s UCJIS Basics and TAC Responsibilities.

An identifier such as AFSPENCERT in the affidavit’s officer-name field is a UCJIS User ID, not a Spillman ID.

Where You See It

UCJIS User IDs appear in affidavits of probable cause in this format:

Officer Name: [UCJIS ID] - [Full Name]

Radio ID

A radio ID is the numeric identifier transmitted by a radio device and shown in recording metadata. An officer may use more than one radio, and a device may be shared or reassigned. A radio ID is distinct from the officer’s spoken call sign.
