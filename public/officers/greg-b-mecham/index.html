About UCJIS User IDs

UCJIS (Utah Criminal Justice Information System) is Utah’s secure criminal justice information system, managed by the Utah Bureau of Criminal Identification (BCI). It provides authorized access to state and federal databases, including the FBI’s National Crime Information Center (NCIC). An agency’s Terminal Agency Coordinator (TAC) assigns each user an individual account and User ID. See BCI’s manuals page for UCJIS Basics and TAC Responsibilities.

An identifier such as AFSPENCERT in the affidavit’s officer-name field is a UCJIS User ID, not a Spillman ID.

About Radio IDs

A radio ID is the numeric identifier transmitted by a radio device and shown in recording metadata. An officer may use more than one radio, and a device may be shared or reassigned. A radio ID is distinct from the officer’s spoken call sign.

Radio associations use the same dated evidence and exclusions as the radio resources table. Evidence counts describe associations, not proof of identity or transcript verification.
