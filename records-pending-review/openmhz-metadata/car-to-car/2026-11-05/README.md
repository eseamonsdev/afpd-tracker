# Car-to-car metadata: November 5, 2026

302 source-exposed calls for talkgroup 6001, using the America/Denver calendar day (2026-11-05T07:00:00Z to 2026-11-06T07:00:00Z, exclusive).

Extracted from uploaded `6001-nov-5` browser HAR. Duplicate API responses were deduplicated by call ID. Calls outside November 5 were excluded. Both midnight boundaries and the older-page cursor chain were checked. Completeness refers to the OpenMHz feed, not every radio transmission.

- `calls.json`: existing project metadata format, including radio IDs, source positions, media URLs, timestamps, frequencies, and full original API objects.
- `source-api-calls.json`: deduplicated original November 5 API objects in chronological order.
- `import-validation.json`: counts, source hash, and validation results.

The original HAR is excluded because it may contain unrelated browsing or session data. This metadata import does not download audio or create transcripts.
